    01

    The amnesia problem you already solved once

    Your app's instructions live in summarizer.py, in a variable called SYSTEM_PROMPT, and your code sends them on every single call without you thinking about it. You have already solved this problem once, in code.

    Now open a chat window and the model has never heard of you. You paste your instructions again. And again. Every new conversation. Every major platform has shipped the same answer: a place to save your instructions so they are applied automatically.

    Visualizer · Who supplies the instructions?Select a setup

    Today you set that up on all three major platforms, and then look at what happened to two of them this month.

    02

    Three ways to make a model remember

    When people say they want AI that "knows our business", they mean one of three different things. They get muddled constantly and they have different answers.

    What you wantWhat it is calledWhat it actually does
    It should always behave this waySaved instructionsYour system prompt, stored and re-sent for you
    It should know these documentsAttached knowledgeYour files sit alongside the chat and the model reads from them
    It should be able to do thingsConnected toolsThe model can call something outside itself

    Today covers the first two. The third is the second half of this module.

    What none of them are

    Important

    None of these train the model. Nothing you type into a skill or a project changes the model itself. Your instructions and your files are supplied to the model at the moment you ask, exactly as if you had pasted them. The platform is doing the pasting. It is automated pasting, not learning, just like SYSTEM_PROMPT in your own file.

    Visualizer · What the model receivesToggle what the platform pastes
    The model's weights: unchanged, in every case
    Why does my assistant seem to get better the more I use it? Common doubt

    Usually because you refined the instructions, not because it learned. Some platforms do have a separate memory feature that carries facts between chats, and that is a different thing. If you did not edit the instructions and it still improved, memory is the likely explanation, or your own prompts got better.

    03

    Gemini Skills, hands-on

    A skill is a saved set of instructions that Gemini applies when it is relevant, or when you call it by name. That is the whole idea. Skills are available on personal Google accounts for users aged 18 and over.

    Build it

      FieldWhat goes in it
      NameLowercase words joined by hyphens, as the placeholder shows: release-notes-writer
      DescriptionOne line on when this skill should be used
      InstructionsThe actual rules, the same shape as your SYSTEM_PROMPT

      Paste this into Instructions:

      Instructions
      You turn rough developer notes into release notes that customers can read.

For every set of notes you receive:
- Lead with what changed for the customer, not what changed in the code
- Group items under: New, Improved, Fixed
- One sentence per item, in plain language
- No ticket numbers, branch names, internal service names or acronyms
- If an item only matters to the team and not to a customer, leave it out

If the notes are too vague to write an entry, list that item under
"Need more detail" instead of guessing what it does.

      Then, in a new chat, type / followed by the skill name and paste these notes:

      Developer notes
      - bumped auth-svc to 2.4.1, fixes the token refresh race (JIRA-8821)
- added dark mode toggle in settings
- cart no longer loses items when you switch tabs
- refactored the payment retry loop, no user visible change
- new export button on reports page, csv only for now
- fixed that thing where the date picker shows wrong month in Safari
      Visualizer · Check the outputIllustrative draft, editable

      Check three things: did it drop the refactor, did it drop JIRA-8821, and did it group correctly. Try both drafts, or edit one.

      Expect some variation: the same instructions do not produce identical behaviour every run. If the refactor line keeps appearing, improve the rule. Change "leave it out" to "leave it out, including anything described as a refactor, cleanup or internal change" and run it again. That is Class 2's iteration loop applied to a saved prompt.

      Differences from a Gem

      You can hold up to 100 active skills, and you can combine several in one chat. But most of the old Gem tools do not work inside a skill, including Deep Research, Canvas and Guided Learning. If you need Deep Research, run it in a normal chat (Section 8).

      Do I have to type the slash every time? Common doubt

      No. Gemini can also apply a skill on its own when it judges it relevant, which is why the Description field matters. The slash is how you force it.

      04

      ChatGPT: the global layer and Projects

      ChatGPT splits the same idea across two features, and knowing which is which saves a lot of confusion. Projects are available on every plan, including Free.

      FeatureScopeUse it for
      Custom instructionsEvery chat you have, everywhereHow you want to be spoken to, always
      ProjectsOnly chats inside that projectA specific job, with its own instructions and files
      Visualizer · Which instructions apply?Choose where you start the chat

      Custom instructions: the global layer

        Example
        I am a backend developer in India. Use metric units and rupees. Give me the answer first and the explanation after. Do not open replies with a compliment.

        The same Personalization page also has preset dials above custom instructions: Base style and tone, Warmth, Enthusiasm, Emoji, Visual answers, and Headers and lists. They are the same idea as a written instruction, pre-packaged, and a good illustration that a preference and a job belong in different places.

        Important

        This is the right slot for preferences and the wrong slot for a job. Anything task-specific belongs in a project, otherwise it leaks into every unrelated conversation you have.

        Projects: the same assistant you just built

          Which of the two gave you the more usable release notes, the Gemini skill or the project? There is no correct answer. This is the Class 1 lesson that the best model is the one that answers your question best, with evidence you generated yourself.

          If I put instructions in both custom instructions and a project, which wins? Common doubt

          Both are applied. They stack rather than compete, which is fine when they agree and confusing when they contradict. Keep preferences global and jobs local and you will not hit it.

          Claude Projects

          Claude's version combines both slots in one place: instructions and files, scoped to a project.

            07

            Attaching knowledge: what a file does and does not do

            This is where expectations get set badly. Attaching a file means the model can use its contents when it answers. It is the grounding idea from Class 3, made permanent for that space instead of pasted per chat.

            What it does

            Answers from your material rather than from memory. Upload your actual refund policy and the answers come from that policy, not from a general sense of what refund policies usually say.

            Survives across chats in that space. You upload once, not every conversation.

            What it does not do

            Does not train the model. Same point as Section 2.

            Does not guarantee it reads all of it. With a lot of material, platforms retrieve the parts that look relevant. A fact in your file can still be missed.

            Does not make answers true. An out-of-date document gives you a confident assistant citing an out-of-date document.

            Visualizer · Retrieval on a 90-page PDFIllustrative page selection

            Solid pages are the parts the platform judged relevant and showed the model. The outlined page is the one you need. Which pages get picked is illustrative: how that judgement is really made is Class 5.

            Important

            The Class 3 rule still applies and matters more here, not less. Add "answer only from the attached files, and say so if it is not in them" to your instructions. Attaching a file does not stop the model falling back on general knowledge unless you say so.

            To see the difference yourself, ask the Release Notes project a question your notes do not cover, such as what the refund window is. Then upload any short policy document and ask again: the answer changes from a general one to a specific, sourced one.

            08

            Deep Research

            All three platforms have a research mode, and it is one of the most used features in any of them. A normal answer takes seconds and comes from one pass. Research mode takes several minutes: the model plans what to look into, runs many searches, reads what it finds, and writes a structured report with citations.

            It is the first thing in this module that visibly thinks and acts in a loop before answering. Hold that thought: that loop is what Class 7 calls an agent.

            Diagram · The research loopStep through

            When it is worth it

            Use research modeUse a normal question
            You would otherwise open fifteen tabsOne fact you can check in one tab
            Comparing options across many sourcesSomething in a document you already have
            You need the sources listed for someone elseYou just need a quick answer for yourself
            The answer should survive being forwardedSpeed matters more than depth

            Writing a brief that gets a good report

            Research mode rewards the same specificity as any prompt, plus two things of its own: say what the comparison axes are, so the report has a spine, and say what the output is for, so the depth and tone fit. Example:

            Research brief
            Compare the three main electric two-wheeler brands available in Pune on price, range, service network and real owner complaints. Cite your sources.

            Launch it early in whichever platform has a free run available, then carry on with something else. When it finishes, scroll the report, find the citation list, and open a few of the citations.

            Try it · Citation checkerClick a citation to cycle its status

            A report comes back with eighteen citations. Select one to cycle: unchecked → checked, supports the claim → checked, does not support it.

            Important

            Everything from Class 3 applies. A research report is far better grounded than a plain answer, because the model is quoting things it actually fetched. It is not verified. The citations are the point, and the point is only worth anything if somebody clicks them.

            On Gemini

            Deep Research does not run inside a skill. It is one of the tools that did not carry over. Run it in an ordinary chat.

            Does it search the whole internet? Common doubt

            It searches what its search tool can reach, which is a lot but not everything, and it cannot see anything behind a login or a paywall. For regulated or academic work, treat the report as a starting map, not a literature review.

            09

            The month both vendors changed their minds

            You set up the same assistant three times and the instructions never changed. Here is why that mattered.

            What happened

            Gemini GemsOpenAI Custom GPTs
            AnnouncedReplaced by skillsRetiring, announced 11 September 2026
            Can you still make oneNo, read-only from 17 November 2026No, creation restricted to Business, Enterprise and Edu
            When it stopsRemoved 17 December 2026Stops running 11 December 2026
            What replaces itSkillsPlugins, with the instructions becoming skills
            Workspace or business accountsMarch 2027, education June 2027Follows each workspace's own notice
            Visualizer · TimelineStatus is relative to the date you open this page

            Two different companies, the same six weeks, the same direction. Both moved from "build a custom assistant object" to "save reusable instructions that the model picks up when relevant", and both called the new thing skills.

            The lesson

            Important

            The valuable thing is your instructions and your files. The feature wrapping them is temporary, and this month is the proof. Keep the text of your instructions somewhere you own, in a document or a repository, and treat every platform's box as a place you paste them into.

            Visualizer · If the vendor retires the boxWhere do your prompts live?

            Your own app already does this correctly. SYSTEM_PROMPT sits in a file you control, and no vendor can retire it. If the honest answer to "where do my prompts live right now?" is "inside one vendor's product", that is today's action item.

            If you had built a product on Custom GPTs in June, the instinct to reach for is an export, a version history, and a thin layer of your own between the vendor and the user.

            10

            Wrap-up and what is next

            What you can do now

            Name the three things

            People mean one of three things by "AI that knows our business", and you can say which one saved instructions solves.

            Set up a reusable assistant

            On all three platforms. A skill is summoned by name mid-chat, a project is a workspace with a history, custom instructions are the global layer.

            Attach knowledge honestly

            You can say what it does and does not buy you.

            Run a research brief

            Its value is in the citations, which means clicking them.

            And you know to keep your instructions somewhere you own, because you watched two vendors retire theirs in the same month.
